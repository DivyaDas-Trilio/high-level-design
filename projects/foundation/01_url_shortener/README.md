# 01 — URL Shortener (TinyURL)

Our first HLD. A deceptively simple system that touches estimation, hashing,
read-heavy scaling, caching, and database choice — without losing structure.

## The 6-step method (our spine)
```
1. Requirements   → scope it (functional + non-functional)        [step_1]
2. Estimation     → numbers that drive every later decision        [step_2]
3. API design     → the contract                                   [step_3]
4. Data model     → entities, schema, access patterns              [step_4]
5. High-level     → boxes & arrows, happy path                     [step_5]
6. Deep dive      → key generation, caching, sharding, trade-offs  [step_6+]
```
